# إعلاني | E3lani — AppsGeyser HTML

نسخة HTML مستقلة (ملف واحد) لتطبيق **إعلاني**، تعمل محليًا داخل المتصفح أو داخل WebView عبر AppsGeyser.

## الفتح في المتصفح

1. افتح الملف مباشرة:
   - انقر نقرًا مزدوجًا على `index.html`، أو
   - اسحبه إلى نافذة المتصفح.
2. يُفضّل استخدام Chrome أو Edge على الهاتف أو سطح المكتب.
3. على سطح المكتب (عرض ≥ 700px) تظهر الواجهة داخل إطار هاتف.

> ملاحظة: بعض المتصفحات تقيّد `localStorage` أو مشاركة الملفات عند الفتح بـ `file://`. إن واجهت مشكلة، شغّل خادمًا محليًا بسيطًا من مجلد `appsgeyser`:
>
> ```bash
> python3 -m http.server 8080
> ```
>
> ثم افتح `http://localhost:8080`.

## التغليف مع AppsGeyser

1. أنشئ تطبيق WebView / HTML في [AppsGeyser](https://appsgeyser.com/).
2. ارفع `index.html` كمصدر الصفحة الرئيسية (أو ارفع المجلد كاملًا إن طلب المنشئ ذلك).
3. عيّن لون السمة / شريط الحالة إلى `#FFC400` إن وُجد الخيار.
4. فعّل صلاحيات التخزين والكاميرا/الملفات إن احتجت رفع الوسائط داخل WebView.
5. ابنِ حزمة APK وثبّتها للتجربة.

البيانات تُحفظ محليًا عبر `localStorage` على الجهاز (`e3lani_ads`, `e3lani_saved`, `e3lani_posts`, `e3lani_profile`, `e3lani_notifications`, `e3lani_market`).
