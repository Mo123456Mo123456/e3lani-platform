# AppsGeyser HTML core

Standalone Arabic RTL HTML build of **إعلاني | E3lani** for packaging with AppsGeyser (or any WebView APK wrapper).

## Use

1. Open `index.html` in a mobile browser, or
2. Upload `index.html` as the start file in AppsGeyser.

Data persists in `localStorage`. Free-launch publishing writes ads into the local feed immediately.

The Expo app in the repository mirrors this core UX (fullscreen feed, market, free create, profile posts).
