# خط أساس متطلبات «إعلاني»

**الحالة:** مرجع تنفيذ داخلي معتمد من ملفات `pasted_content.txt` و`pasted_content_2.txt` و`pasted_content_3.txt` ومن طلب صورة الحساب الأخير. لا يُعد أي بند مكتملًا إلا عند وجود تنفيذ واختبار ودليل تحقق.

## 1. تعريف المنتج

«إعلاني» منصة محتوى إعلاني مرئي للأفراد والبراندات والمتاجر. لكل معلن صفحة عامة مجانية ينشر فيها محتواه، ويمكنه تحويل منشور محدد إلى توزيع إعلاني في الرئيسية دون إعادة رفع الوسائط. المنصة ليست متجرًا، ولا تعالج بيع المنتج أو توصيله أو عمولته، ولا تضيف تعليقات أو محادثات أو قصصًا أو مزادات أو سلة مشتريات.

> صفحتك الإعلانية مجانًا، وانتشارك يبدأ عندما تختار.

## 2. القرارات المعمارية الملزمة

| المجال | القرار الملزم |
|---|---|
| مصدر الحقيقة | Backend وقاعدة البيانات هما المصدر المركزي للحسابات والمحتوى والإعلانات والإعدادات والصلاحيات والمدفوعات والبلاغات والإحصاءات. |
| التخزين المحلي | يقتصر على التفضيلات والكاش والمسودات المؤقتة، ولا يمثل بيانات المنصة المركزية. |
| الوسائط | تخزين سحابي بمفاتيح غير متوقعة، وروابط موقعة أو عامة حسب الاستخدام، ومعالجة خادمية، ومنع الاعتماد على URI محلي دائم. |
| المصادقة | لا OTP ثابتًا في الإنتاج، ولا صلاحيات إدارية من العميل، ولا أسرار داخل التطبيق. |
| المنشورات والإعلانات | `profile_posts` للمحتوى المجاني و`ad_distributions` للتوزيع المدفوع أو المجاني؛ السجلان مرتبطان ولا يكرران الوسائط. |
| الدفع | معطل افتراضيًا. لا نجاح وهمي ولا فاتورة مدفوعة تجريبية. عند تفعيله يعمل عبر Payment Provider Adapter وWebhook متحقق منه. |
| الإعدادات | الأسعار والمدد وأوضاع الخلاصة والحدود والخصائص من قاعدة البيانات ولوحة الإدارة، لا من ثوابت الواجهة. |
| الأدوار | RBAC خادمي للأدوار `guest`, `user`, `advertiser`, `brand_owner`, `moderator`, `support`, `finance`, `admin`, `super_admin`. |
| الذكاء الاصطناعي | يقترح ويفحص في الخلفية، ولا ينشر نصًا دون موافقة المستخدم، ولا يحظر حسابًا نهائيًا دون قرار بشري. |

## 3. أوضاع التشغيل المركزية

| الوضع | السلوك |
|---|---|
| `PROFILE_ONLY` | النشر داخل الصفحة مجاني، ولا يصل شيء إلى الرئيسية إلا بقرار الإدارة. |
| `FREE_LAUNCH` | الترويج إلى الرئيسية مجاني خلال فترة الإطلاق، بلا شاشة دفع أو عملية وهمية، ومدة افتراضية 30 يومًا. |
| `PAID_ONLY` | النشر داخل الصفحة مجاني، والترويج يتطلب طلبًا ودفعًا مؤكدًا ومراجعة قبل بدء مدة الظهور. |

الإعداد الافتراضي للنسخة الحالية هو `FREE_LAUNCH` مع حفظ سعر مستقبلي **59 ريالًا لكل 30 يومًا** في الإعدادات فقط، وليس عرضه كتدفق دفع ما دام الدفع معطلًا.

## 4. نموذج المحتوى

| الكيان | المسؤولية |
|---|---|
| `profile_posts` | المنشور الأصلي المجاني داخل صفحة المعلن. |
| `post_media` | صور أو فيديو المنشور بترتيبها وبياناتها وملفاتها المعالجة. |
| `ad_distributions` | حملة ظهور مرتبطة بمنشور، لها حالة وفترة وقسم ومدينة وزر إجراء وسعر مستقل. |
| `ad_events` | مشاهدات وتفاعلات مرتبطة بسجل التوزيع مع إزالة التكرار واستبعاد صاحب الإعلان. |
| `daily_metrics` | تجميع يومي للإحصاءات دون خلط أداء المنشور المجاني بأداء الحملة. |

انتهاء الترويج يخفي الإعلان من الرئيسية فقط؛ يبقى المنشور الأصلي في صفحة المعلن ويمكن ترويجه مجددًا مع حملة وإحصاءات مستقلتين.

## 5. الحساب وصفحة المعلن

حساب الفرد يعرض صورة اختيارية أو أول حرف، والاسم والنبذة والمدينة والروابط والمنشورات والإعلانات النشطة. حساب البراند أو المتجر يعرض شعارًا داخل مربع بحواف خفيفة، وصورة غلاف، واسم البراند والنبذة والمتجر وواتساب والاتصال وروابط التواصل والمنشورات والإعلانات وشارة التوثيق عند توفرها.

صورة الحساب أو الشعار تخزن في حقل مستقل عن صور الإعلانات، مع متغيرات صغيرة ومتوسطة وكاملة. تغييرها أو حذفها ينعكس على جميع الإعلانات السابقة والجديدة لأن الواجهة تحل هوية المعلن عند القراءة بدل نسخ رابط الصورة إلى سجل الإعلان.

## 6. معالجة صورة الحساب

| الشرط | معيار القبول |
|---|---|
| الأنواع | JPG وPNG وWebP فقط. |
| الحجم | حد أقصى 5MB في العميل والخادم. |
| القص | مربع 1:1 قبل الرفع. |
| المعالجة | ضغط وإنشاء thumbnail وmedium وfull. |
| الأمان | تحقق من MIME والتوقيع، فحص محتوى مخالف، ورصد احتمال انتحال براند ليرسل للمراجعة البشرية. |
| الصلاحية | التغيير والحذف لصاحب الحساب أو دور مخول فقط. |
| الحذف | إزالة المراجع من قاعدة البيانات وتنظيف الملفات القديمة بأمان. |
| العرض | صورة دائرية للفرد، ومربع بحواف دائرية خفيفة للشعار، وFallback إلى الحرف الأول. |

## 7. رحلة النشر والترويج

رحلة المنشور المجاني لا تتجاوز: اختيار الوسائط، العنوان أو الاقتراح، القسم، الرابط أو وسيلة التواصل، ثم المعاينة والنشر. الوصف والقسم الفرعي والمدينة والروابط الإضافية اختيارية، مع حفظ مسودة وتقدم رفع حقيقي وإلغاء وإعادة محاولة.

بعد النشر تظهر رسالة «تم نشر المحتوى في صفحتك» وزر مستقل «روّج في الرئيسية». الترويج يعيد استخدام الوسائط نفسها ويطلب نطاق العرض وزر الإجراء ويعرض معاينة كاملة الشاشة ثم ينشئ `ad_distribution` مستقلًا.

## 8. الخلاصة والتوصيات

الخلاصة تعرض إعلانًا واحدًا كامل الشاشة، بسحب عمودي بين الإعلانات وأفقي بين صور الإعلان، مع مشغل فيديو واحد مرئي فقط وحفظ إعداد الصوت. المعلومات فوق الوسائط مختصرة: المعلن وصورته، العنوان، زر الإجراء، الحفظ، المشاركة، والإبلاغ.

تبويب «لك» يعتمد في البداية على المدينة والأقسام والحداثة والجودة والتنوع وعدم التكرار، ثم يضيف إشارات التفاعل. «قريب منك» يعتمد على المدينة أو الموقع المصرح به، و«الأحدث» ترتيب زمني حقيقي. لا يجوز اختزال التبويبات الثلاثة إلى مصفوفة واحدة بترتيب شكلي.

## 9. المراجعة والسلامة

الفحص يغطي النص والصور وإطارات الفيديو والصوت والنص المرئي والرابط ورقم التواصل ونوع المنتج أو الحساب. التصنيف: `SAFE`, `NEEDS_REVIEW`, `BLOCKED`. الحظر النهائي للحساب قرار بشري. المنتجات والأصول الرقمية والحسابات والمحتوى عالي المخاطر تحتاج إقرارًا ومراجعة أعلى، مع بلاغات واعتراض وسجل قرار وأثر تدقيق.

## 10. الإدارة والتتبع

لوحة الإدارة متصلة بالخادم وتدير المراجعة والمستخدمين والأدوار والبراندات والأقسام والمدن والأسعار والأوضاع والحدود والبلاغات والاستئنافات والإعدادات والإشعارات وسجل التدقيق. جميع الأحداث المهمة لها timestamps وهوية منفذ وسبب عند الحاجة.

## 11. الويب العام

توجد صفحات عامة قابلة للفهرسة للإعلانات والأقسام والمدن والمعلنين، مع canonical وOpen Graph وTwitter Cards وJSON-LD وSitemap وrobots وصفحات الخصوصية والشروط والسلامة والإبلاغ. لا تُعد نسخة Expo Web وحدها دليلًا على SEO حقيقي قبل التحقق من HTML العام والفهرسة.

## 12. بوابة الجودة

لا يُعلن عن الجاهزية للإطلاق قبل نجاح TypeScript والبناء واختبارات الوحدة وAPI وقاعدة البيانات والصلاحيات والوسائط والفشل الشبكي وE2E والأداء والأمان. يجب توثيق المزودات والـENV والمهاجرات وSeed وFeature Flags ووضع الدفع وخطوات الاسترجاع، مع قائمة صريحة بأي فجوات متبقية.
