# محرك المحاكاة / Simulation Engine

## المبادئ

1. **حتمية كاملة**: `run_history(seed, ticks, injections)` تعيد إنتاج نفس الحالة بايت-بايت (يُثبتها `hash_state` SHA-256 في الاختبارات).
2. **كل التغير أحداث**: لا تتغير حالة الكوكب «عشوائيًا» — كل نظام يبرر كل حدث (سبب صريح أو رابط سببي أو حمولة تفسيرية `reason/driver/causes`).
3. **عشوائية مشتقة فقط**: كل سحب عشوائي يمر عبر `Rng(seed, system, tick)` — بذور مشتقة BLAKE2b، فلا يتأثر الناتج بترتيب القواميس أو الجدولة.
4. **Event Sourcing + Snapshots**: إعادة التشغيل = توليد + حقن مجدولة + تقديم. Snapshots كل 25 tick تسرّع الرجوع.

## الشبكة

شبكة خطوط عرض/طول (`latBands × lonBands`، افتراضي 36×72 = 2592 خلية). كل خلية تحمل: ارتفاع، حرارة أساسية، رطوبة، biome، خصوبة، مياه عذبة/أنهار، تلوث، غطاء نباتي، مالك حضارة، مدينة، رواسب موارد، عداد جفاف. الشبكة محاذية لفضاء UV للكرة ⇒ كل طبقة محسوبة تُرسم مباشرة كخامة.

## التوليد الإجرائي

```
fBm ارتفاعات + قناع قارات + ridged جبال
→ مستوى بحر → BFS مسافة محيط/يابسة
→ حرارة = خط العرض − تدرّج ارتفاع + ضجيج
→ رطوبة = ضجيج + قرب المحيط (اضمحلال أسّي) − قمم
→ أنهار: مصادر مرتفعة رطبة → هبوط حتى المحيط (مياه عذبة + خصوبة)
→ براكين: ذروة Worley متناثرة
→ Biome: تصنيف Whittaker على (حرارة, رطوبة, ارتفاع) + مستنقعات
→ 14 نوع مورد × أوزان biome × غنى Worley (120 رواسب)
→ 800 نبات (أنماط أصلية لكل biome، انتشار ابتدائي متجمع)
→ 300 مخلوق (هرم غذائي: 55% عواشب/25% قوارت/20% لواحم، فرائس بحجم أصغر ونفس النطاق)
→ 12 حضارة في أفضل المواقع (خصوبة + مياه + ساحل + تباعد)
```

كل ذلك من بذرة واحدة ⇒ **نفس الـ seed يعيد نفس الكوكب**.

## الترتيب الثابت للأنظمة في كل Tick

1. **المناخ** — ميزان CO₂ (انبعاثات الحضارات − امتصاص الغطاء)، انجراف حراري عالمي (±)، انجراف biomes بتدرّج، عواصف تتشكل على محيط دافئ وتتحرك مع أحزمة الرياح، فيضانات قرب الأنهار، جفاف متسلسل → تصحير، حرائق في غابات جافة حارة، ثورات بركانية (تدمير محلي + رماد).
2. **البيئة** — نمو لوجستي للنباتات نحو سعة biome مع منافسة وماء-إجهاد وامتصاص تلوث، انتشار جوار؛ ديناميكيات فريسة-مفترس (Lotka–Volterra مُلهمة) مع Carrying Capacity لكل نوع/خلية، هجرة نحو موائل أفضل، طفرات → أنواع فرعية، انقراض تحت عتبة.
3. **الحضارات** — محاسبة (غذاء/استخراج/تلوث/صحة/سعادة/استقرار) ثم **Utility AI**: توسّع (مدن جديدة على أفضل الخلايا)، بحث، تجارة، تحالف، هجرة تحت الإجهاد، علاج، تغيير حكم، انهيار/انشقاق. الذاكرة تُغذي القرارات (grievances/trust).
4. **الاقتصاد** — إنتاج/استهلاك/ندرة؛ طرق تجارة بين مدن متحالفة/متصالحة عبر **Dijkstra** على رسم تكاليف التضاريس (الجبال والصحاري ومناطق الحرب أغلى)؛ المسارات تُخزن وتُرسم وتنقل المرض والتقنية.
5. **الحروب** — نقاط بنيوية (ندرة موارد مشتركة، احتكاك حدودي متراكم، مظالم تاريخية، خلل قوة، ضغط سكاني، عدوانية، ردع تحالفي، ثقة)؛ لا حرب عشوائية: يجب تجاوز العتبة مع `causes` موثقة. النتيجة: قوة × تقنية × تضاريس × إمداد × معنويات × حظ محدود. العواقب: احتلال، لاجئون، معاهدات، انهيارات، ضغط ابتكار، مرض.
6. **الأمراض** — تفشٍّ من كثافة+صحة منخفضة، انتشار جوارٍ وطرق تجارة، وفيات ضد الطب، احتواء.
7. **التقنية** — تقدم بحثي يفتح طبقات (مكافآت زراعة/عسكرية/طب/سعة/ملاحة)، انتشار عبر التجارة، انجراف ثقافي.
8. **التأثيرات المؤجلة** — ظواهر وقوانين عالمية مساهم بها تنبض لاحقًا.

## الحقن (مساهمات المستخدم)

`inject` يحوّل خصائص منظمة إلى كيان فعلي: البحث عن أفضل الخلايا (لياقة بيئية حول الهدف أو عالميًا)، سكان/حضور أولي من سعة الحمل، ثم يعمل كل شيء عبر الأنظمة العادية بعد ذلك — لا «نتائج مكتوبة». الجذر: `CONTRIBUTION_APPLIED`/حدث الفئة مع `contributionId`، وكل نسله عبر `causeEventId`.

## سيناريوهات مونت كارلو

تفرّعات مستقلة (بذور مشتقة `mc_run`) لكل أفق (1/10/100/1000 سنة؛ خطوات أخشَن للآفاق الطويلة): مقاييس (سكان، حضارات، انقراضات، حروب، تلوث، انحراف حراري، أحداث في الشجرة السببية للمساهمة) → **الأكثر احتمالًا/الأفضل/الأسوأ + عدم يقين + محركات الاختلاف**. النتائج احتمالية صراحة — لا تنبؤ مؤكد.

## اختبارات الحتمية والثوابت (36 اختبارًا)

- نفس الـ seed ⇒ نفس التوليد ونفس التاريخ بعد N tick (حتى بعد JSON round-trip).
- إعادة تشغيل كاملة مع حقن مجدولة ⇒ نفس الحالة.
- لا حضارة حية بلا مدن؛ لا حدث بلا سبب/تفسير؛ السكان ضمن السعة؛ الهجرات على اليابسة فقط؛ الحروب لها causes وتتجاوز العتبة؛ معرّفات أحداث متسلسلة.

## English

Deterministic, event-sourced tick engine over a lat/lon grid aligned to globe UV space. Fixed system order per tick (climate → ecology → civilizations → economy → conflicts → diseases → technology → pending effects). All randomness derives from seeded BLAKE2b streams per (system, tick). Generation: fBm/ridged/Worley noise → BFS ocean distance → temperature/moisture → rivers → volcanoes → Whittaker biomes → resources → plants → food-web species → civilizations. Wars are structurally scored with documented causes; trade paths use Dijkstra over terrain costs; Monte-Carlo forks produce probabilistic futures. 36 pytest tests prove determinism, replay, and invariants.
