# Algorithms

- RNG: Mulberry32-style deterministic stream seeded by FNV-1a hash.
- Noise: seeded 2D Perlin implementation with octaves for elevation, moisture, temperature, and volcanic activity.
- Biomes: classified from height, moisture, temperature, and volcanic signal.
- Ecosystem: Lotka-Volterra-inspired population update with logistic carrying capacity.
- War scoring: weighted pressure vs dampening model.
- Pathfinding: Dijkstra over weighted graphs for trade and migration planning.
- Causality: event IDs link through a causal graph; no event is accepted without a cause.
