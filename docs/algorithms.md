# الخوارزميات — Algorithms

## 1. توليد الكوكب (Procedural Planet Generation)

المدخل: بذرة نصية + أبعاد شبكة (افتراضي 144×72 خلية خط-طول). المخرجات قابلة لإعادة التوليد حرفيًا في أي بيئة.

| الطبقة | الخوارزمية |
|---|---|
| الصفائح التكتونية | مراكز Voronoi (8–14) بأنواع محيطية/قارية ومتجهات انجراف؛ الحدود المتقاربة (محسوبة من اتجاه الانجراف) ترفع جبالًا وتفعّل براكين |
| الارتفاع | Simplex fBm (5 أوكتافات) × ridged noise + انحياز نوع الصفيحة + تعزيز الحدود |
| الحرارة | منحدر خط العرض (33° − 0.62·|lat|) + تأثير الارتفاع (−30°/km نسبي) + ضوضاء + اعتدال محيطي |
| الرطوبة | نطاقات عرضية (مدارية/جافة/غربية) + ضوضاء fBm + تعزيز ساحلي + **ظل مطر**: تتبع 4 خلايا عكس الرياح السائدة (تجارية/غربيات) فإن وُجد حاجز أعلى تُخصم الرطوبة |
| الأنهار | اتجاه الجريان لأدنى جار (كسر التعادل بهاش حتمي) + تراكم التدفق بترتيب الارتفاع؛ `river = log2(1+accum)/9` |
| المناطق الحيوية | تصنيف Whittaker معدّل على (حرارة، رطوبة، ارتفاع، بركانية، جليد): 12 نمطًا |
| الموارد | جداول احتمال لكل نمط حيوي (جبال→حديد/نحاس/ذهب، صحراء→نفط/شمس، بركانية→بلّور/حرارة جوفية…) بكميات ومعدلات تجدد |
| الغطاء النباتي | 800 سلالة إجرائية بخصائص مسحوبة حتميًا وتوزيع بيومي |
| المخلوقات | 300 نوع بأصناف حجمية، شبكة غذاء (الضواري تصطاد الأصغر من نفس الوسط)، سكان ابتدائي عبر مشي توسعي |
| الحضارات | 12 موطنًا على خلايا عالية الخصوبة ساحلية/نهرية بمسافة فاصلة ≥ 7 خلايا، إقليم ابتدائي BFS، تقنيات عصر حجري |

## 2. المناخ (Cellular Automata)

- إجبار دفيئي: متوسط تلوث الخلايا المأهولة × حساسية القانون العالمي؛ الهباء البركاني يبرد مؤقتًا.
- خلايا آلية لكل خلية/نبضة: العواصف تتولد على ماء دافئ (>25°) وتنجرف مع نطاق الرياح وتضعف على اليابسة وتلحق ضررًا بالسواحل؛ الجفاف يتراكم وينتهي بعودة الرطوبة؛ الحرائق في (جفاف+حرارة+غطاء) وتنتشر؛ الفيضانات (نهر قوي + عاصفة)؛ الثورات البركانية (احتمال ثابت صغير) تدمر محليًا وتخصب لاحقًا وتحجب الشمس؛ ذوبان الجليد يرفع البحر ويبتلع السواحل المنخفضة فوق +1.5°.
- التلوث ينتشر انتشارًا (86% بقاء + 12% متوسط الجيران) وتمتصه النباتات — ومنها نباتات المستخدمين المقتفاة خليةً خلية.

## 3. البيئة الحيوية

- نمو لوجستي `dP = r·P(1−P/K)` لكل نوع في كل خلية مشغولة؛ `K` من ملاءمة الموطن (نمط + حرارة + ماء + غطاء نباتي) وعقوبة الحجم.
- افتراس مستوحى من Lotka–Volterra: استهلاك الفريسة المشاركة للخلية بنسبة من الافتراس، بانتقال كتلة حيوية جزئي.
- هجرة شرطية: ازدحام (>92% K) أو تدهور الملاءمة ⇒ أفضل جار صالح؛ عبور المحيط للأنواع المائية أو عالية الحركة فقط (مختبَر).
- طفرات بمعدل `mutationRate` تتضاعف تحت الإجهاد ⇒ سلالات فرعية بخصائص مهتزة، وانقراض تحت عتبة بقاء.

## 4. الحضارات (Agent-Based + Utility AI)

كل حضارة تحدّث احتياجاتها ثم **تُسجّل نقاطًا لأفعال** وتنفذ الأعلى:

| الفعل | محركات النقاط |
|---|---|
| التوسع | ضغط سكاني + أرض خصبة حرة مجاورة + فائض غذائي |
| بناء مدينة | سكان > 3500·(مدن)^1.4 مع قيد مسافة |
| التجارة | عجز اقتصادي + شريك متكامل (سلع متباينة) ضمن مدى لوجستي |
| التحالف | علاقات > 0.55 + عدو مشترك |
| الحرب | ضغينة (−علاقة) + توتر موارد + عدوانية + تفوق قوة — **مضروبًا بقانون العالم** — وعتبة 0.72 وتهدئة 12 سنة |
| الهجرة | أمن غذائي < 0.45 أو استقرار < 0.25 |
| الإصلاح | استقرار < 0.32 ⇒ تغيير نظام الحكم |

## 5. الحروب (لا تبدأ عشوائيًا)

القوة = عسكرية × تقانة عسكرية × استقرار × سكان × حلفاء (35% لكل حليف فعال). الجبهة = خلايا الحدود. كل نبضة:

`attPow = قوة المهاجم × عامل الإمداد(مسار العاصمة→الجبهة / مدى اللوجستيات) × (1 − عقوبة الطقس)`
`defPow = قوة المدافع × إمداد × (1 + ميزة التضاريس: جبال/مستنقعات/أنهار)`

الزخم يتحرك نحو النسبة؛ الاستيلاء على خلايا عند |زخم|>0.4؛ خسائر وإنهاك ولاجئون (هجرات بمسار A* صالح)؛ نهاية عند |زخم|>0.9 أو 20 سنة أو انهيار استقرار — معاهدة، تعويضات، تدمير/نقل مدن، واحتمال انهيار حضارة وقيام خلافة ثورية (كلها أحداث مسببة).

## 6. الاقتصاد والمسارات

- استخراج مقيد بالتقنية (النفط يتطلب `oil_refining`…) وبنفاد الرواسب (`RESOURCE_DEPLETED`).
- طرق التجارة عبر **A\*** على الشبكة: كلفة = تضاريس + عواصف + أراضي طرف ثالث؛ البحر مفتوح فقط بملاحة الطرفين. قيمة الطريق من تكامل الفائض، ويُقطع بالحرب.
- الأمراض تتفشى بالكثافة والحرب وتنتشر جوارًا وعبر طرق التجارة؛ الاحتواء بتقنيات الطب أو الزمن.

## 7. توازن العناصر

قبل دخول أي عنصر: سقف لكل خاصية (0.98)، ميزانية مجموع (6.0)، تركيبات محظورة (خلود+تكاثر، طاعون كوني، طاقة لا نهائية، سيطرة مطلقة)، ثم اقتراح نسخة متوازنة مع قائمة تعديلات شفافة بدل الرفض الصامت.
