# سياسة الإعلانات — إعلاني | E3lani

## المسموح

كل إعلان مشروع ونظامي: متاجر، منتجات، خدمات، عقارات، سيارات، وظائف، فعاليات، مطاعم، سفر، تطبيقات، مواقع، حسابات اجتماعية، تغطيات، صناع محتوى، ألعاب وبطولات مشروعة، تصميم وتسويق، أسر منتجة، تبادل وتبرع.

لا يُرفض الإعلان فقط لأنه متعلق بمنصة اجتماعية أو لعبة.

## المحظور

- الأسلحة والمتفجرات والمخدرات
- الاحتيال وانتحال الهوية
- الحسابات المسروقة وبيانات الدخول
- الاختراق والبرمجيات الضارة والتجسس
- المقامرة
- المحتوى الجنسي الصريح
- السلع المقلدة والوثائق المزورة
- الخدمات غير المرخصة والأدوية المقيدة
- الغش في الألعاب
- انتهاك الملكية الفكرية
- أي محظور حسب دولة الإعلان

الحالات غير الواضحة → `NEEDS_CHANGES` أو مراجعة بشرية مع حق الاستئناف.

## حدود المنتج

المنصة إعلانات مرئية وتواصل مباشر — ليست متجرًا إلكترونيًا ولا وسيط بيع. لا سلة، لا Checkout للمنتجات، لا شحن، لا عمولة بيع، لا مزاد، لا محادثات داخلية، لا تعليقات، لا بث مباشر، ولا تحويل صور إلى فيديو.
