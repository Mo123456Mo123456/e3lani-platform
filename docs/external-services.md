# ربط الخدمات الخارجية

## 1) SMS وOTP

طبقة `OtpProvider` موجودة في `services/api/src/auth.ts`. مزود `console` مسموح في التطوير فقط ويوقف التشغيل إذا استُخدم في الإنتاج.

لإضافة مزود:

1. أنشئ class يطبّق `OtpProvider.send(phone, code)`.
2. استخدم مهلة اتصال قصيرة وإعادة محاولة محدودة لدى المزود فقط.
3. استبدل provider في `AppModule` وفق `OTP_PROVIDER`.
4. لا تسجل الرمز أو `SMS_API_KEY` في الإنتاج.
5. اترك التخزين hash فقط، وحد المحاولات ومدة الخمس دقائق كما هما.

## 2) S3 / MinIO

أنشئ bucket خاصًا، واضبط CORS ليسمح بـ `PUT` من تطبيقات الويب المعتمدة فقط. لا تجعل الملفات الأصلية عامة. واجهة API توقع رفعًا مدته 15 دقيقة، ثم يتحقق العامل من البصمة الفعلية ويكتب النسخ المعالجة.

المتغيرات: `S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_FORCE_PATH_STYLE`, `MEDIA_PUBLIC_URL`.

في الإنتاج يفضّل تقديم `processed/` خلف CDN مع منع فهرسة `original/`.

## 3) Redis وBullMQ

استخدم Redis يدعم persistence وTLS. يجب أن يشترك API والعامل في `REDIS_URL`. قائمة `media-processing` تستخدم job id مطابقًا لمعرف الوسيط لمنع التكرار، وثلاث محاولات مع exponential backoff.

## 4) الدفع

الدفع متوقف افتراضيًا. لا تغيّر `PAYMENTS_ENABLED=true` حتى يتوفر adapter إنتاجي يطبق:

- إنشاء intent لدى المزود.
- توقيع webhook والتحقق من raw body.
- idempotency على معرف حدث المزود وعلى `PaymentOrder.idempotencyKey`.
- تسوية المبلغ والعملة من قاعدة البيانات، لا من العميل.
- refund موثق وAudit Log.

لا يعتبر redirect من المتصفح إثبات دفع. `DisabledPaymentProvider` يتعمد الفشل ولا يولد نجاحًا تجريبيًا.

## 5) Push

يُربط Expo Push أو مزود APNs/FCM داخل worker إشعارات مستقل عند التوسع. الإشعار داخل التطبيق محفوظ في PostgreSQL أولًا؛ فشل Push لا يلغي العملية الأساسية.

## 6) فحص المحتوى

الفحص المحلي الحالي يتحقق من النوع، البصمة، الحجم، المدة، سلامة التحويل، الحقول، وبنية الروابط. اربط مزود رؤية/سلامة عبر adapter قبل الإنتاج للكشف المتقدم. القرار الآلي الواضح فقط يرفض الرفع؛ المراجعة البشرية تبدأ بعد بلاغ أو حالة استثنائية، لا في مسار النشر العادي.

## 7) أسرار الإنتاج

- استخدم secret manager، ولا ترفع `.env`.
- ولّد `JWT_SECRET` عشوائيًا بطول 32 بايت على الأقل.
- افصل مفاتيح Sandbox وProduction وحسابات buckets.
- فعّل rotation، وسجل تغيير الإعدادات الحساسة.
- اجعل `ADMIN_ORIGIN` نطاقًا مستقلاً خلف WAF/MFA أو VPN عند الحاجة.
