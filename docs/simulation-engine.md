# محرك المحاكاة

## التوليد

`generateWorld(seed)` يأخذ عينات على كرة باستخدام إحداثيات ثلاثية الأبعاد حتى
لا يظهر خط فاصل عند ±180°. تمزج الخوارزمية عدة Octaves من value/fractal noise
للقارات والتضاريس والحرارة والرطوبة، ثم تصنف Biome وتحسب إمكانات الماء
والمعادن والكتلة الحيوية والخصوبة والطاقة.

نفس Seed والإعدادات ينتجان JSON مطابقًا. الشبكة الافتراضية 18×36، ويمكن تغييرها
حتى الحدود الموجودة في `WorldConfigSchema`.

## Tick

كل Tick:

1. ينشئ `SeededRandom` من `world.seed + tick`.
2. يحسب تغير المناخ من الكربون والتذبذب المحدود.
3. يطبق نموًا لوجستيًا لا يتجاوز carrying capacity.
4. يخفض التلوث بعمليات طبيعية مرتبطة بالرطوبة.
5. يقيّم الهجرة والمرض والبراكين ونضوب الموارد بشروط سببية.
6. يقيّم قرارات حضارية أولية للتقنية والتحالف والتجارة والحرب.
7. يخرج أحداثًا مستقلة وروابطها السببية، ثم Projection جديدة غير mutable.

الاحتمالات ليست `Math.random()`؛ جميعها مشتقة من Seed، لذلك يمكن إعادة التاريخ.

## المساهمات

الحزمة المشتركة تدعم حاليًا نباتًا وموردًا ونوعًا وحضارة وتقنية. لكل مساهمة:

- تحقق Zod صارم.
- ملاءمة المنطقة والـBiome.
- ميزانية أثر محدودة.
- إنشاء `CONTRIBUTION_ADDED` ثم حدث مباشر.
- أحداث ثانوية للسكان أو التلوث عند وجود تغير فعلي.
- منع السكان من تجاوز القدرة الاستيعابية.

API يقبل وصفًا حرًا، يستعمل AI Adapter كطبقة استشارية، ثم يعيد حساب الأرقام
حتميًا في `domain/effects.ts`. لا تمر دلتا المزود إلى Commit.

## Monte Carlo

`projectFutureScenarios` يشغّل مسارات ببذور فرعية ثابتة ويعيد:

- السيناريو الوسيط (likely).
- أعلى Score (best).
- أدنى Score (worst).
- نطاقات 10–90% للسكان والحرارة والتلوث.

هذه مسارات احتمالية وليست وعودًا. API يعرض أيضًا p10/median/p90 لكل Metric
لمعاينة المساهمة.

## الثوابت المختبرة

- نفس Seed = نفس العالم.
- Replay للأحداث = نفس الحالة.
- لا حدث دون Cause.
- لا حضارة دون Population ومساحة استيعاب.
- لا يتجاوز السكان carrying capacity.
- لا تنقل الهجرة السكان إلا إلى Neighbor صالح.
- مخرجات AI المتطرفة لا تستبدل الأثر الخوارزمي.
