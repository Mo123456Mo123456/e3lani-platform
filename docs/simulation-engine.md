# محرك المحاكاة — Simulation Engine

## النبضة (Tick)

كل نبضة تمثل سنة واحدة افتراضيًا (قابل للضبط: يوم/شهر/سنة/عقد عبر `yearsPerTick`). ترتيب الأنظمة داخل النبضة ثابت وحتمي:

```
tick++
1. الإضافات المعلّقة المستحقة (مساهمات المستخدمين)
2. المناخ والجيولوجيا   systems/climate.ts
3. البيئة الحيوية        systems/ecology.ts
4. الحضارات (وكلاء)      systems/civilization.ts
5. الحروب                systems/conflict.ts
6. التحالفات             systems/conflict.ts
7. الهجرات               systems/conflict.ts
8. الاقتصاد والتجارة     systems/economy.ts
9. لقطة دورية كل snapshotInterval نبضة
```

## الحتمية (Determinism)

- كل العشوائية تمر عبر `RngStream` (mulberry32) متفرعًا من البذرة.
- التفريع `rng.fork(label)` مشتق من **بذرة الأساس لا من عداد السحب** — استقرار تام مهما اختلفت أعداد السحوب.
- سياق كل نظام يستخدم تسمية ثابتة: `tick:{n}:{phase}` — نفس البذرة + نفس العمليات ⇒ نفس التاريخ بتطابق البت.
- السيناريوهات تضيف ملحًا للتسمية (`:scenario:{horizon}:{run}`) فتتباعد المسارات عن بعضها بينما يبقى كل مسار حتميًا.
- الاختبار: تشغيلان مستقلان (60+ نبضة مع إضافات) يجب أن يتطابقا في `hashWorld` وقائمة الأحداث كاملة.

## Event Sourcing واللقطات

- كل تغير حدث مستقل `WorldEvent` بمعرف حتمي وبيانات سببية (`causeIds`, `actorIds`, `contributionId`, `confidence`, `magnitude`).
- **القاعدة الصارمة**: لا حدث بلا سبب. الاستثناءات الوحيدة الموثقة: أحداث التكوين الأربعة (تكوين الكوكب، المحيطات، الحياة، النباتات) و`ELEMENT_ADDED` (فعل المستخدم الجذري). اختبار آلي يفحص ذلك على 50 نبضة كاملة.
- لقطة كل 50 نبضة: تسلسل كامل للحالة + هاش + عداد الانبعاث `seq` (يُستعاد عند الاسترجاع ليتطابق توليد المعرفات اللاحق مع مسار جديد).
- الاسترجاع `rollback(tick)`: استعادة الحالة من اللقطة، حذف الأحداث اللاحقة، إعادة بناء الفهارس — ثم يكمل المحرك نفس المستقبل الحتمي (مختبَر).

## الرسم السببي (Causal Graph)

كل حدث يشير إلى أسبابه. `CausalGraph` يبني شجرة الأحفاد لأي حدث (عمق 5 افتراضيًا)، وتُعرض في «الخريطة السببية» لمساهمة المستخدم: الإضافة → التأثيرات الأولية → الثانوية → طويلة المدى. تُخزَّن الحواف في جدول `CausalLink` للاستعلام التاريخي.

## سيناريوهات المستقبل (Monte Carlo)

`runScenarioSet(engine, [1,10,100,1000], runs=7)`:
1. تسلسل الحالة الحالية مرة واحدة.
2. لكل أفق: `runs` نسخ مستقلة بملح RNG مختلف (عقد لكل نبضة للآفاق ≥ 100 سنة لضبط الكلفة).
3. تجميع: توزيع النقاط (p10/p50/p90)، درجة عدم اليقين (انتشار نسبي)، والعوامل الأكثر تأثيرًا (تباين المقاييس عبر المسارات).
4. النصوص المعروضة (الأكثر احتمالًا/الأفضل/الأسوأ) تُصاغ من حقائق المسارات عبر طبقة السرد المؤسَّس — **لا يُعرض تنبؤ مؤكد أبدًا**.

## الحالة المسلسلة

`serializeWorld` يحوّل الخرائط والمجموعات إلى JSON خالص (مع نسخ عميق — اللقطات لا تشارك مراجع مع الحالة الحية)، و`deserializeWorld` يعيدها. الهاش عبر `stableStringify` بترتيب مفاتيح ثابت.
