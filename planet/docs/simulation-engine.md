# محرك المحاكاة / Simulation Engine

## الحتمية (Determinism)

كل عشوائية تمر عبر `RngState = { seed, counters }`: كل سحبة هي دالة نقية
`mix(seed ⊕ hash(stream) ⊕ counter)`. جدول العدّادات جزء من حالة العالم، فاللقطات
وإعادة التشغيل تعيد نفس المتتاليات حرفيًا. التيارات المسماة ("climate", "war"…)
تعزل أنظمة عن بعضها — إضافة سحبة في نظام لا تبدّل عشوائية غيره.

**إثبات مُختبَر:** نفس seed → نفس checksum بعد 60 tick؛ لقطة + إعادة تشغيل → نفس الحالة؛
سلسلة تجزئة الأحداث تكشف أي عبث.

## توليد الكوكب (Procedural Generation)

1. **صفائح تكتونية**: مراكز Voronoi على الكرة (12 صفيحة) + اتجاه انجراف لكل صفيحة؛
   الإجهاد عند الحدود (فرق المسافة لأقرب وثاني أقرب مركز) يقود الجبال والبراكين.
2. **الارتفاع**: fBm مُشوَّه المجال (domain-warped) + ridged عند الحدود المتقاربة.
3. **مستوى البحر**: من مدرج تكراري لتحقيق نسبة محيط مستهدفة (~62%).
4. **الحرارة**: خط العرض + التدرج الارتفاعي + ضجيج محلي.
5. **الرطوبة**: نقل مع الرياح السائدة (تجارية/غربية) مع المطر الأروغرافي وظل المطر.
6. **الأنهار**: من مرتفعات رطبة، تدفق انحداري إلى البحر.
7. **البيومات**: 12 صنفًا من (خط العرض، الارتفاع، الحرارة، الرطوبة، البركانية) —
   وتُعاد التصنيف كل 5 ticks مع تغيّر المناخ (التصحر حقيقي).

## نظام النبضات (Ticks)

ترتيب ثابت كل tick: مناخ → بيئة → حضارات → اقتصاد → صراعات → هجرات → أمراض → حقب.
`yearsPerTick` قابل للضبط (يوم/شهر/سنة/عقد).

| النظام | الخوارزميات |
|---|---|
| المناخ | Cellular automata: انتشار تلوث/رطوبة، ذوبان جليد، براكين/حرائق/فيضانات باحتمالات مسببة |
| البيئة | نمو لوجستي + Carrying Capacity، افتراس بأسلوب Lotka–Volterra، طفرات، انقراض |
| الحضارات | Utility AI: توسع/مدن/بحث/تجارة/حرب/تحالف بدرجات منفعية من الحاجة والتاريخ |
| الاقتصاد | استخراج/ندرة/نفاد، طرق تجارة A*، تكلفة مسافة |
| الصراعات | قوة = جنود×تقنية×تضاريس×إمداد×طقس×تحالفات؛ خسائر، نزوح، معاهدات |
| الهجرات | ضغط (مجاعة/حرب/مناخ) → A* نحو موائل أفضل — لا عبور مستحيل (مُختبَر) |
| الأمراض | تفشٍ من الكثافة، انتشار جوارًا وعبر طرق التجارة، احتواء بالصحة |

## Event Sourcing

كل تغيّر حدث: `{seq, tick, year, type, cellIndex, payload, causes[], confidence,
contributionId, importance, hash}` — السلسلة `hash = fnv1a(prevHash + stable(event))`.
الرسم السببي يجيب: «ماذا حدث بسبب إضافة المستخدم X؟» (أسلاف/أحفاد).

## اللقطات وRollback

`structuredClone` للحالة الكاملة؛ التسلسل JSON يحوّل TypedArrays. الـ Rollback =
أقرب لقطة ≤ الهدف + إعادة تشغيل حتمية للفارق (مُختبَر مطابقة checksum).

## Monte Carlo للمستقبل

`runFutureScenarios`: لكل أفق (١/١٠/١٠٠/١٠٠٠ سنة) تُستنسخ branches ببذور مشتقة
حتميًا → تشغيل → تسجيل (صحة المحيط الحيوي، ازدهار الحضارات، التلوث، الأحداث)
→ أفضل/أسوأ/أرجح + عدم يقين (تباين الفروع) + عوامل مؤثرة. **لا يُعرض تنبؤ مؤكد
أبدًا — دائمًا احتمالات**، والمعاينة لا تلمس العالم الأصلي (مُختبَر).
