# الأمان / Security

## المصادقة والجلسات

- Access token JWT قصير (15 دقيقة) في الذاكرة؛ Refresh عشوائي 48 بايت في كوكي
  HttpOnly + SameSite=strict + Secure (إنتاج) — محصور بمسار `/auth`.
- **Refresh Token Rotation** مع كشف إعادة الاستخدام: تقديم رمز مبطل يبطل عائلة
  الرموز كلها ويُسجَّل في AuditLog (مُختبَر).
- bcrypt بتكلفة 12؛ Suspension يبطل كل الرموز فورًا.

## التخويل

- RBAC بعشرة أدوار هرمية؛ الحراس على مستوى Nest (`JwtAuthGuard` + `RolesGuard`).
- تغيير الأدوار يمنع منح دور أعلى من دور الفاعل.
- لوحة الإدارة تطبيق منفصل لا يُربط من الواجهة العامة + تحقق دور عند الدخول.

## حماية المدخلات والإخراج

- Zod على كل نقطة إدخال (API + خدمات)؛ Prisma يمنع SQL injection بناءً.
- الإشراف: Prompt Injection / تهريب شيفرة / إساءة / تكرار / طول — قبل أي تحليل.
- مخرجات AI المنظمة تُتحقق قبل لمس المحرك؛ السرد يُفلتر بالتأسيس.
- ترميز مخرجات React الافتراضي (لا dangerouslySetInnerHTML لمحتوى المستخدم).

## حدود المعدل

- عام: 120/دقيقة/IP · المصادقة: 10/دقيقة/IP · الإضافات: 20/ساعة/مستخدم · السرد: 30/دقيقة.

## الترويسات والنقل

- `x-content-type-options`, `x-frame-options: DENY`, `referrer-policy`,
  `permissions-policy`, وCSP في الواجهة (تُشدَّد على الحافة للإنتاج).
- WebSocket يتطلب JWT عند الاتصال؛ الاشتراكات محصورة بالعوالم المعلنة.

## التدقيق والسلامة

- AuditLog لكل حسّاس (تسجيل، أدوار، إيقاف، rollback).
- سلسلة تجزئة الأحداث (`verifyEventChain`) — أي عبث بالسجل يُكشف.
- Secrets عبر البيئة فقط؛ `.env` مُستبعد من git؛ مفاتيح AI اختيارية (Sandbox بديل آمن).

## النسخ والاسترداد

- أحجام Docker دائمة (`db-data`, `engine-data`)؛ لقطات المحرك دورية على القرص.
- Rollback مدروس بصلاحية simulation_manager ويُدقَّق.
