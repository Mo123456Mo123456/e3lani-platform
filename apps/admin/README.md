# @planet/admin

Dark-themed ops console for **كوكب يولد أمامك**. Port **3001**.

```bash
pnpm --filter @planet/admin dev
```

Requires `NEXT_PUBLIC_API_URL` (default `http://localhost:4000`).

Allowed roles: `admin`, `super_admin`, `sim_manager`, `content_mod`.

Super Admin credentials are documented in the root README only — never linked from the public web app.
