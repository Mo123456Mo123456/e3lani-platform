# Prototypes

## `e3lani-appsgeyser.html`

Standalone Arabic RTL free-launch prototype for AppsGeyser / local HTML packaging.

It mirrors the product core:

- Full-screen vertical ad feed with «لك / قريب منك / الأحدث»
- Brand ticker
- Free publish (no payment)
- Categories + market selector (🌍 All countries / SA / AE / EG)
- Saved ads, profile posts, report sheet, localStorage persistence

Use this file as the UX reference for the Expo `feature/fullscreen-feed` and `feature/free-launch-mode` work, or wrap it directly in AppsGeyser for a local APK preview.
