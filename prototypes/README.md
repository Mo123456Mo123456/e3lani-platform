# AppsGeyser / HTML core prototype

`appsgeyser-e3lani.html` is the standalone Arabic RTL HTML core for إعلاني | E3lani.

It matches the free-launch product surface:

- fullscreen vertical ad feed with ticker, tabs (لك / قريب منك / الأحدث), save/share/report/contact
- categories with SA / AE / EG market switcher
- free publish form (media, title, description, category, country, city, scope, contact)
- saved list, search, notifications
- profile with ads / free posts

The Expo app under `app/(tabs)` was aligned to this core UX while keeping the existing local store and paid create flow available at `/create-ad`.
